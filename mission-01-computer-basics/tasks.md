# MISSION 1 - Know your computer

## Task 1.1 – Trace one activity using IPOS

### Activity -> Saving a file on your computer

| Stage | What happens in your example? | Possible hardware / component |
| --- | --- | --- |
| Input	| Mouse used to click the save button | Mouse / Keyboard used to navigate to the save button. |
| Processing | CPU manages the request of saving and moves the temporary data to permanent data and handles the file permissions. | CPU is used and RAM is also used as initially before the file was saved, the data was live on the RAM. | 
| Output | Monitor shows that the file is saved on your computer | Monitor displays the output. |
| Storage | The file is stored on your SSD/HDD | SSD/HDD is where the final file will be stored after the processing is completed. |
