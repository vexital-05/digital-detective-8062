# digital-detective-8062

#### This repository is contains the answers to the Digital Detective Assignment. Its main objective is to understand how the computer works, practice basic terminal operations, explore how the operating system manages files and programs, understand how numbers and text are represented and use Github to publish the work.  
#### These objectives are broken down into missions, which have their own README file in their respective folders. Each mission is completed and committed seperately.

---
## Folder Structure based on the missions assigned:
| Mission | Purpose |
| --- | ---- |
| [mission-00-setup](mission-00-setup/README.md) | Setup details, tools and repository information. |
| [mission-01-computer-basics](mission-01-computer-basics/README.md) | IPOS, hardware, software and everyday systems. |
| [mission-02-terminal](mission-02-terminal/README.md) | Terminal activities and command learning. |
| [mission-03-operating-system](mission-03-operating-system/README.md) | OS, processes, paths, storage and permissions. |
| [mission-04-programs](mission-04-programs/README.md) | Python test and compiler/interpreter comparision. |
| [mission-05-number-data](mission-05-number-data/README.md) | Conversions, encoding and converter explaination. |
| [mission-06-git-github](mission-06-git-github/README.md) | Git workflow, branch and Pull request learning. |
| [mission-07-networking](mission-07-networking/README.md) | Network concepts and observations. |
| [mission-08-final-report](mission-08-final-report/README.md) | Final review and submission checklist. |
| [evidence](evidence/README.md) | Privacy-safe screenshots or selected output, grouped by mission |
